论文(设计)选题目的、工作任务

论文（设计）选题目的：
在高校日常学习中，自习室座位资源紧张，占座、预约后不到场等问题突出，传统现场占座与人工登记方式难以掌握座位的实时状态，管理效率低、纠纷多。本课题拟设计并实现一套基于 B/S 架构的校园自习室预约管理系统，采用 Vue 3 与 TypeScript 构建前端，Node.js、Express 与 Sequelize 构建后端服务，结合 MySQL 实现座位、时段与预约数据的高效存储与查询，并接入 JWT 身份认证与二维码签到，支持学生在线查询、选座预约、扫码签到、取消预约及违约查询。系统前端将包括面向学生的预约界面与面向管理员的后台管理界面，提升自习室座位资源的利用效率与管理水平。
工作任务：
在规定时间内完成项目的需求分析、系统设计、技术选型与功能模块划分；开发学生端及管理端应用，实现自习室与开放时段配置、座位批量维护、预约与签到、违约管理、反馈工单、统计报表等功能模块；完成系统的部署测试，确保各项功能稳定运行；最终提交可运行的系统成果及配套的毕业设计论文文档。
