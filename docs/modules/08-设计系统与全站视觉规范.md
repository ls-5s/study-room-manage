> 实现日期：2026-11-11

## 1. 模块目标

M08 建立全站统一的视觉语言与交互基线，使登录、学生端、管理端和错误页面共享同一套色彩、字体、间距、圆角、材质和状态反馈。

本模块只改变前端表现层，不新增后端接口、数据库表、权限规则或业务状态机。

主要目标：

- 用雾银石墨与低饱和冰川蓝建立清晰、克制的视觉识别。
- 深色和浅色主题保持同等完整的组件与页面覆盖。
- 学生端保持舒展的阅读节奏，管理端保持更高的筛选和表格效率。
- 毛玻璃和渐变只服务空间层级，不影响正文对比度。
- 统一 Element Plus 控件、ECharts 图表和页面级容器的视觉行为。

## 3. 视觉基准

### 3.1 色彩

浅色主题：

- 画布 `#f1f3f4`，表面 `#fbfcfc`，抬升表面 `#ffffff`。
- 主要文字 `#11181c`，正文辅助 `#46555c`，说明文字 `#5f6d74`。
- 强调色 `#2f6b7e`，主操作背景 `#172126`。

深色主题：

- 画布 `#080c0f`，表面 `#11171b`，抬升表面 `#151c21`。
- 主要文字 `#f2f5f6`，正文辅助 `#b8c1c6`，说明文字 `#849198`。
- 强调色 `#7db9cd`，主操作背景 `#eef2f3`。

状态色固定为低饱和成功、提醒和危险色，并同时配合图标、文字和形状表达，颜色不是唯一状态信号。

### 3.2 字体与版式

- 全站使用 `Noto Sans SC Variable`。
- 字体文件由 Fontsource 按 Unicode 范围分片加载，使用 `font-display: swap`，不额外预加载全部中文字体分片。
- 页面标题使用 32–48px 的响应式范围，区块标题使用 18–24px，正文和表格使用 14–16px，辅助信息不低于 12px。
- 中文标题使用紧致负字距与稳定行高，正文使用 1.6–1.8 行高。

### 3.3 空间与层级

- 间距统一从 4、8、12、16、24、32、40、48、64、80、96 中选择。
- 圆角统一为 8、12、16、24 和胶囊五档。
- 卡片不嵌套卡片；列表筛选、数据面板和状态摘要使用连续的页面层级。
- 学生页面采用较大留白和更明显的 Hero，管理页面使用较紧凑的工具栏、表格和指标带。

### 3.4 渐变、毛玻璃与光影

- Hero 使用冰蓝、雾银和极淡暖灰的多层径向与线性渐变。
- 工作区背景使用低强度环境光与 64px 细网格。
- 侧栏、顶栏、认证表单、移动抽屉和弹层使用半透明背景与背景模糊。
- 主要操作按钮使用深石墨或雾白主色向冰蓝偏移的轻微渐变。
- 毛玻璃不用于大面积正文容器，以免降低可读性和性能。

## 4. 应用壳层

### 4.1 桌面布局

- 左侧导航宽度 248px，使用玻璃表面、分组标题、细描边选中态和 2px 强调线。
- 顶栏高度 72px，保留面包屑、账号信息、主题切换、环境标识和退出操作。
- 主内容区域最大宽度 1480px，页面路由切换使用 260–360ms 的透明度与短距离位移动画。

### 4.2 移动布局

- 900px 以下隐藏固定侧栏，使用全高玻璃抽屉导航。
- 720px 以下页面 Hero、表单和卡片改为单列。
- 390px 宽度下禁止页面级横向溢出，数据表格只在自身容器内滚动。

## 5. 组件规范

- 主按钮：墨色或雾白实底，一处页面只保留一个主要操作。
- 次按钮：透明或表面背景，使用可见边界。
- 输入框：实色表面、可见控制边界和 3:1 焦点环。
- 表格：取消默认条纹和重复边框，使用细分隔线、稳定数字列和统一操作区。
- 标签：使用胶囊形状，同时提供图标或明确文字。
- 对话框、抽屉和消息：使用玻璃表面、16px 圆角、柔和阴影和背景模糊。
- 空态、加载和错误：保留内容区尺寸，提供明确原因和下一步操作。

## 6. 主题与图表

- 首次访问跟随系统主题，用户切换后保存到本地。
- 主题切换同步更新页面、Element Plus 弹层、移动抽屉和 ECharts。
- 图表颜色从全局 CSS Token 读取，不在业务页面重复硬编码。
- 图表 Tooltip、图例、坐标轴、网格和空态都使用同一主题变量。
- 支持 `prefers-reduced-motion`，减少动效时禁用位移和长过渡。
- 不支持背景模糊或减少透明效果时自动回退到实色表面。

## 7. 设计系统页面

路由：`/admin/design-system`

权限：

- 仅 `admin` 和 `super_admin` 可访问。
- 页面不读取或修改业务数据。

页面内容：

- 独立深色、浅色预览切换。
- 语义 Token 与 neutral、accent、success、warning、danger 完整色阶。
- 字体比例、数字样式和组件样张。
- 预约控制台、表格、分页、空态、加载和错误状态。
- 座位预约玻璃场景与设计原则。

调试入口：

```text
管理后台 -> 设计系统
```

2. 1280px、1024px、390px 下检查页面级横向溢出。
3. 检查深色、浅色主题以及 ECharts 主题切换。
4. 检查移动导航抽屉、键盘焦点、加载态、空态和错误提示。
5. 检查设计系统色值复制、章节导航和预览主题切换。

- 管理员端 36 组页面与尺寸组合无横向溢出。
- 学生端 18 组页面与尺寸组合无横向溢出。
- 浏览器控制台无错误。
- 页面正文和辅助文字对比度满足可读要求。
