## 1. 模块目标

统计与报表模块为管理员提供预约、签到、失约和座位利用情况的可视化摘要，并支持导出当前筛选结果。

第一版完成：

- 管理员仪表盘和近七天趋势。
- 按日期、自习室和开放时段的统计报表。
- 每日计划容量快照和实时使用聚合。
- 历史统计冻结。
- UTF-8 BOM CSV 导出。
- 7 天本地演示数据。

第一版不实现预约提交量、取消记录切换开关、学生个人统计、Redis 缓存或分布式任务调度。

## 3. 数据设计

### 3.1 `daily_statistics_runs`

每日运行表解决“当天没有资源数据”和“快照任务没有执行”无法区分的问题。

| 字段                      | 类型     | 约束 | 说明             |
| ------------------------- | -------- | ---- | ---------------- |
| `stat_date`               | DATE     | 主键 | 东八区业务日期   |
| `capacity_snapshotted_at` | DATETIME | 非空 | 容量快照完成时间 |
| `finalized_at`            | DATETIME | 可空 | 当日统计冻结时间 |
| `created_at`              | DATETIME | 非空 | 创建时间         |
| `updated_at`              | DATETIME | 非空 | 更新时间         |

### 3.2 `daily_slot_metrics`

| 字段                     | 类型            | 说明                     |
| ------------------------ | --------------- | ------------------------ |
| `id`                     | BIGINT UNSIGNED | 主键                     |
| `stat_date`              | DATE            | 统计业务日期             |
| `room_id`                | BIGINT UNSIGNED | 自习室外键               |
| `room_name_snapshot`     | VARCHAR(64)     | 快照名称                 |
| `slot_id`                | BIGINT UNSIGNED | 开放时段外键             |
| `slot_label`             | VARCHAR(32)     | 快照名称                 |
| `slot_start_time`        | TIME            | 快照开始时间             |
| `slot_end_time`          | TIME            | 快照结束时间             |
| `bookable_seat_count`    | INT UNSIGNED    | 计划可预约座位数         |
| `available_seat_minutes` | BIGINT UNSIGNED | 计划容量座位分钟         |
| `reservation_count`      | INT UNSIGNED    | 非取消预约场次，含待签到 |
| `checked_in_count`       | INT UNSIGNED    | 已签到和已完成场次       |
| `no_show_count`          | INT UNSIGNED    | 失约场次                 |
| `outage_cancelled_count` | INT UNSIGNED    | 系统停机取消场次         |
| `used_seat_minutes`      | BIGINT UNSIGNED | 已签到预约计划分钟       |
| `finalized_at`           | DATETIME        | 行冻结时间               |
| `created_at`             | DATETIME        | 创建时间                 |
| `updated_at`             | DATETIME        | 更新时间                 |

唯一键为 `(stat_date, room_id, slot_id)`。资源外键使用 `ON UPDATE RESTRICT ON DELETE RESTRICT`。

### 3.3 容量快照

- 只纳入状态为 `open` 的自习室、`active` 的开放时段和 `available` 的座位。
- 资源 `bookable_from` 必须不晚于统计日期。
- `available_seat_minutes = bookable_seat_count × 时段分钟数`。
- 每天首次统计任务执行时创建当天快照；即使没有可统计资源，也会写入每日运行记录。
- 计划容量一旦创建，普通后台改名、停用座位或关闭房间不会追溯修改当天分母。

### 3.4 实时刷新与历史冻结

- 统计任务在应用启动时立即执行，之后每 60 秒刷新当前日使用数据。
- 每天 01:10 后冻结前一天。冻结前先运行预约状态修复任务，确保不存在待签到或应完成但未完成的预约。
- 冻结在单个事务中完成：刷新使用分钟、写入行冻结时间、更新每日运行记录。
- 冻结失败时整日回滚并在下一分钟重试，不产生部分冻结数据。
- 已冻结历史数据不会被普通统计查询静默重算。

## 4. 指标口径

### 4.1 日期和时间

- 日期使用 `Asia/Shanghai` 自然日。
- 默认趋势范围为截至今天或所选结束日期的最近 7 天。
- 单次范围最多 366 天，未完整提供开始和结束日期时返回 422。
- 未来日期不参与统计查询。
- 历史查询要求对应每日运行记录已经冻结，否则返回 `409 CONFLICT`。

### 4.2 预约场次

```text
reservationCount =
  pending + checked_in + completed + no_show
```

所有状态均按预约的 `reserve_date` 归属。普通取消和系统停机取消均不进入预约场次。

系统停机取消通过预约状态日志中的固定原因单独识别，并写入 `outage_cancelled_count`。

### 4.3 已签到与已结算

```text
checkedInCount = checked_in + completed
settledReservationCount = checkedInCount + no_show
```

未来仍为 `pending` 的预约计入预约场次，但不进入签到率和失约率分母。

### 4.4 比率

```text
signInRate = checkedInCount / settledReservationCount
noShowRate = noShowCount / settledReservationCount
utilizationRate = usedSeatMinutes / availableSeatMinutes
```

- 接口比率保留 4 位小数。
- 前端百分数保留 1 位小数。
- 分母为 0 时比例返回 0，并提供 `hasSettledData=false` 或 `hasUtilizationData=false`。
- 多维汇总先累加计数和分钟数，再计算比率，禁止平均各行比率。

### 4.5 座位利用率

已签到和已完成预约使用计划时长近似：

```text
usedSeatMinutes = sum(end_at - start_at)
```

失约预约不计入使用分钟；这是失约会降低利用率的业务定义。当前日使用完整日计划容量作为分母，不按当前时刻截断。

## 5. 接口设计

所有统计接口仅允许 `admin` 和 `super_admin`。

### 5.1 概览

`GET /admin/statistics/overview?date=2026-11-11`

`date` 可省略，默认今天。响应包含：

- `cards`：预约场次、已签到、失约和利用率。
- `rates`：签到率、失约率、系统停机取消数、已结算数和空数据标记。
- `dataStatus`：`live` 或 `finalized`。
- `generatedAt`、`finalizedAt` 和固定时区。

### 5.2 趋势与分组

`GET /admin/statistics/trend?dateFrom=2026-11-05&dateTo=2026-11-11&groupBy=day&roomId=`

`groupBy` 只允许：

- `day`：按日期分组并补齐范围内缺失日期。
- `room`：按自习室汇总，名称取范围内最后一天的快照名称。
- `slot`：按快照开始和结束时间组成稳定的 `HH:mm-HH:mm` 分组键。

每项返回预约、签到、失约、停机取消、已结算数、计划容量分钟、使用分钟、三类比率和两个空数据标记。

### 5.3 CSV 导出

`GET /admin/statistics/export`

参数与趋势接口一致。响应为附件，不走 JSON 响应包裹。

固定列为：

```text
分组,分组名称,预约数,已签到数,失约数,系统停机取消数,签到率,失约率,利用率
```

导出规则：

- UTF-8 BOM，兼容 Excel 中文。
- CRLF 换行，所有单元格双引号包裹。
- 双引号写为两个双引号。
- 以 `= + - @`、制表符或回车开头的文本增加前导单引号。
- 文件名格式为 `study-room-report-YYYYMMDD-YYYYMMDD.csv`。
- 分母不存在时比率单元格为空。

## 6. 前端页面

### 6.1 管理仪表盘 `/admin/dashboard`

- 日期选择和刷新。
- 预约场次、已签到、失约、利用率四个指标卡。
- 近七天预约与签到折线图。
- 签到率柱状和失约率折线组合图。
- 自习室利用率排行。
- 开放时段预约分布。
- 数据状态、更新/冻结时间和系统停机取消说明。
- 与图表使用同一数据的文字表格。

### 6.2 统计报表 `/admin/reports`

- 日期范围、分组维度和自习室筛选。
- 场次结构和结算质量图表。
- 当前分组结果表格。
- 导出当前筛选结果，导出期间禁用重复点击。
- 非 JSON 错误响应会解析业务错误并显示可读提示。

页面使用 ECharts 6.1.0 按需注册图表模块。共享图表组件使用 `ResizeObserver` 调整尺寸，并在卸载时调用 `dispose`。页面支持明暗主题、桌面和移动布局。

## 7. 演示数据

执行：

```powershell
pnpm --dir backend db:seed:statistics
```

脚本行为：

- 为最近 7 天准备当前开放房间和时段的演示指标。
- 前 6 天标记为已冻结历史。
- 今天调用真实实时聚合逻辑。
- 不修改用户、自习室、时段、座位或预约记录。
- 重复执行不会创建重复唯一键记录。
